# Purchase-Order-Workflow-Automation
This project automates the Purchase Order (PO) approval process using n8n, Google Sheets, and Gmail, eliminating manual follow-ups and status tracking. Tools used: n8n| Google Sheets

## 1. Comprehensive Project Overview

The objective of this project was to redesign a manual, email-driven PO approval process into a **fully automated, auditable workflow**. The solution triggers approvals based on predefined business rules, updates PO status in real time, and notifies stakeholders automatically.

The project simulates a realistic procurement scenario where approval requirements depend on PO value thresholds, showcasing how automation can reduce delays, errors, and operational overhead while improving process transparency.

## 2. Skills Acquired / Demonstrated

- Business process automation using **n8n**
- Designing event-driven and conditional workflows
- Translating approval policies into executable logic
- Integrating operational systems (Sheets, Email) into a single workflow
- Reducing manual effort through rule-based automation
- Building scalable, auditable operational processes
- Applying automation to real-world procurement use cases

## 3. Business Impact

- Reduced manual follow-ups in PO approvals
- Improved approval turnaround time
- Increased process visibility and consistency
- Created a reusable foundation for document-driven procurement automation
